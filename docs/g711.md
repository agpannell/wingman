# G.711 voice sample decoding

G.711 represents one voice sample in one byte using **A-law** or **mu-law**. Both give quiet signals
finer amplitude steps than loud signals. This unequal spacing is called **companding**. It saves
space compared with a two-byte PCM16 sample, while discarding some amplitude precision. Decoding
recovers the quantized amplitude; it cannot recover information lost during encoding.

Use `wingman.g711` to expand raw G.711 bytes from a voice stream or an already parsed audio file.
Choose the law specified by that stream or file. Every byte is valid under both laws, so their
contents cannot establish which law was intended. The decoder preserves sample order and leaves
sampling rate, channel layout, packet handling and container parsing to the caller.

Use [Zig 0.17.0 and the package setup](../README.md#use-it-in-a-project). From a checkout, run
`zig build g711-example` for a complete example that expands both laws and writes their PCM16 bytes.

## Choose the result representation

| API | Result |
| --- | --- |
| `Law` | `.alaw` or `.mulaw`; selected explicitly for bulk conversion |
| `decodeAlaw(byte) i16` | One exact signed PCM16 value in `[-32256, 32256]` |
| `decodeMulaw(byte) i16` | One exact signed PCM16 value in `[-32124, 32124]` |
| `decodeInto(source, destination, law)` | `destination[0..source.len]` as normalized `f32` samples |
| `DecodeError` | `DestinationTooSmall` or `Aliasing`, diagnosed before any output mutation |

PCM16 here means an integer amplitude in the signed 16-bit scale. It does not specify a byte order.
Use `std.mem.writeInt` or [PCM16 encoding](pcm.md#encode-normalized-pcm16) when producing bytes for a file.

A-law's closest amplitudes to silence are **-8** and **+8**; it has no exact zero. Mu-law's **0x7f**
and **0xff** codes both expand to integer zero. The raw mu-law **0x00** code expands normally to
**-32124**. Network zero-suppression rules are outside this amplitude decoder.

```zig
const std = @import("std");
const g711 = @import("wingman").g711;

test "exact scalar amplitudes" {
    try std.testing.expectEqual(-8, g711.decodeAlaw(0x55));
    try std.testing.expectEqual(8, g711.decodeAlaw(0xd5));
    try std.testing.expectEqual(0, g711.decodeMulaw(0x7f));
    try std.testing.expectEqual(0, g711.decodeMulaw(0xff));
    try std.testing.expectEqual(-32124, g711.decodeMulaw(0x00));
}
```

`decodeInto` divides each PCM16 integer by **32768**. Every integer and the power-of-two scaling
are exactly representable in `f32`; normalization introduces no additional rounding error. Both
mu-law zero codes become positive floating-point zero. This scaling follows the signed PCM16
range, rather than stretching each law's largest amplitude to one.

```zig
const std = @import("std");
const g711 = @import("wingman").g711;

test "caller-owned normalized output" {
    const source = [_]u8{ 0, 128, 127, 255 };
    var destination: [6]f32 = @splat(42);
    const samples = try g711.decodeInto(&source, &destination, .mulaw);
    try std.testing.expectEqualSlices(
        f32,
        &.{ -32124.0 / 32768.0, 32124.0 / 32768.0, 0, 0 },
        samples,
    );
    try std.testing.expectEqualSlices(f32, &.{ 42, 42 }, destination[4..]);
    try std.testing.expectError(
        error.DestinationTooSmall,
        g711.decodeInto(&source, destination[0..3], .mulaw),
    );
}
```

## Storage, lifetime and failure

All operations allocate nothing and retain no source, output, allocator or scheduler. The bulk
result borrows the caller's destination; its length equals the number of source bytes. Source
storage can be released after the call returns. An empty source succeeds and changes no output.

Bulk admission checks occur in this order:

1. Reject `DestinationTooSmall` when the destination has fewer samples than the source has bytes.
2. Reject `Aliasing` if the source overlaps the **used output's byte span**.
3. Expand every byte and return the used output prefix.

Both refusals preserve the entire destination. A capacity refusal takes precedence even if the
same call would also overlap. Touching spans are disjoint, and source may occupy unused destination
capacity. Successful conversion preserves spare output. Every admitted byte expands successfully;
there is no later malformed-sample or nonfinite-value failure.

## Compose with PCM16 output

The [PCM library](pcm.md) writes normalized samples as little-endian PCM16. G.711 results lie on
its exact PCM16 grid, so this composition recovers the scalar decoder values without another
quantization change. It does not add G.711 encoding or infer a WAVE header.

```zig
const std = @import("std");
const wingman = @import("wingman");

test "mu-law to little-endian PCM16" {
    const source = [_]u8{ 0, 128, 127, 255 };
    var samples: [source.len]f32 = undefined;
    const decoded = try wingman.g711.decodeInto(&source, &samples, .mulaw);
    var bytes: [source.len * 2]u8 = undefined;
    const encoded = try wingman.pcm.encodePcm16Into(decoded, &bytes);
    try std.testing.expectEqualSlices(u8, &.{ 0x84, 0x82, 0x7c, 0x7d, 0, 0, 0, 0 }, encoded);
}
```

## How expansion works

Each code carries a sign, an amplitude segment and a position within that segment. Expansion
undoes the law's transmitted bit inversion, reconstructs the segment's quantized magnitude, then
applies its sign. Segment spacing grows with magnitude; mu-law's bias produces its two zero codes.
The scalar implementation uses integer arithmetic directly, without a retained lookup table.

Inline tests compare all 512 law/code combinations with independent segment centers and steps.
They also cover normalized words, source alignment, short/exact/spare output, error precedence,
overlap in both directions, touching spans and source inside unused capacity. Separate consumer
tests exercise public calls and PCM composition. These checks make no throughput claim.

The [ITU-T G.711 core recommendation](https://www.itu.int/rec/T-REC-G.711/en) defines the two laws.
G.711 encoding, law transcoding, G.711.0 lossless frames, concealment, comfort noise, rate conversion
and playback are outside this library's current surface.
